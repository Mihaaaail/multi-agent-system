# Мафия с уликами

Четыре лабораторные работы по теории многоагентных систем. Девять игроков получают неполные сведения о скрытых ролях. Жители пытаются найти сообщников, а сообщники тайно согласуют подозрения против жителей. Ночная проверка даёт ещё одну улику с известной вероятностью ошибки. После четырёх ночей игроки составляют итоговый список подозреваемых.

## Посмотреть партию

Откройте [demo.html](https://mihaaaail.github.io/multi-agent-system/demo.html) в браузере. Страница показывает трассы, полученные при запуске модели. Выберите правила, переключайтесь между днями и откройте тайные роли и бюллетени, чтобы увидеть сговор и смены голосов. Все показанные режимы используют один начальный мир. Правила партии меняются, исходные роли и улики в этом наборе совпадают.

## Запустить модель

Нужен Python 3.10 или новее. Используется стандартная библиотека. Все команды выполняются из общей папки проекта.

~~~text
python -m mafia play
python -m mafia play --method host --silent --mafia 2
python -m mafia play --scenario combined --guarded --trace results/party.json
python -m mafia experiment all
python -m mafia demo --seed 206600 --out results/another-demo.html
python -m unittest discover -s tests -v
~~~

Команда опыта по умолчанию пишет новые данные в папку `results`. Можно указать номер работы вместо `all`, `--games` для другого числа пар и `--out` для другой папки. Параметр `--seed` позволяет повторить конкретный начальный мир. Для списка остальных параметров запустите `python -m mafia play --help`.

Сценарий `normal` означает штатную игру, `rumor` добавляет согласованный слух, `bad_check` искажает первый ночной ответ, `offline` отключает основной источник на две ночи, `combined` объединяет слух и ошибочный ответ. Параметр `--guarded` отделяет мнения от улик и подключает резервный источник.

## Как устроены агенты

- [agents.py](mafia/agents.py) содержит локальные оценки, отбор аргументов и стратегии голосования. Жители оценивают, как публикация улики изменит выбор группы. Сообщники подбирают правдоподобного кандидата среди жителей и могут придержать невыгодное наблюдение.
- [game.py](mafia/game.py) задаёт среду, доставку сообщений, голосование, проверку и доверие к ранее высказанным свидетельствам. Открытые переговоры идут двумя этапами. Ответы на первом этапе становятся видны всем до начала второго.
- [experiments.py](mafia/experiments.py) повторяет игры на парных исходных данных и сохраняет измерения. Средние доли представлены в диапазоне от 0 до 1, интервалы оцениваются по разбросу парных разностей.

В таблицах `check_precision` означает долю назначенных проверок, пришедшихся на сообщников, `recall` — долю всех сообщников в итоговом списке, `solved` — полное раскрытие состава, `false_rate` — долю жителей, попавших в итоговый список. `deliveries` учитывает каждого получателя рассылки. `vote_changes` считает смены выбора между намерением до обсуждения и бюллетенем после него. `usable_clues` и `wrong_clues` относятся к принятым ночным уликам. `disagreements`, `outages` и `unsupported` считают расхождения источников, недоступные ночные ответы и публичные мнения без улики.
